# Changelog

## 0.6.1

### Исправлено
- Запуск `claude` в терминале, когда нет расширения Claude Code, на Windows: запрос экранируется под PowerShell (в том числе типографские апострофы), в cmd запускается `claude`, а запрос остаётся в буфере. Команды установки плагина склеиваются без `&&`, которого нет в Windows PowerShell 5.1.
- Обновления панели больше не накладываются: опрос, фокус окна и события файлов во время расчёта сводятся в один повтор, устаревший расчёт не перезаписывает свежий.

### Изменено
- Ответы `gh pr list` кэшируются на 2 минуты, а не запрашиваются каждые 30 секунд и при каждом фокусе окна. Кнопка «Обновить» сбрасывает кэш.

## 0.6.0

### Добавлено
- **PR с правкой спеки**: кнопка «Предложить PR с правкой спеки», когда в `spec-gaps.md` есть расхождение с нужной правкой спеки без PR. Запрос в Claude Code: правка change в отдельном клоне репозитория спек, проверки спек, push и PR — после подтверждения разработчика, ссылка — в поле «PR спеки». Сабмодуль спек только читается.
- В `spec-gaps.md` читаются поля «Правка спеки» и «PR спеки»; стоппер «решено обновить change, PR со спекой нет».
- **План в репозитории спек**: `design.md`, `plan.md` и `spec-gaps.md` из `openspec/changes/<change>/plans/<репозиторий>/`. Вариант — настройка `sddFlow.plansLocation`, `plans:` в `.cex-sdd.yaml` или наличие каталога в спеке; тег «план в спеке» в шапке, прогресс — с `plan.md` из `main` спек.

## 0.5.4

### Изменено
- Ключ задачи — любого проекта трекера (`TN-130`, `ABC-7`), а не только одного: в ветке, `tasks.md`, метках `sdd-temp(…)` и мастере «Начать задачу». Ключ в ветке пишется заглавными в начале имени или сразу после `feat/`, `fix/` и т. п.
- В README, подсказках и примерах условный ключ `TN` (TaskName).

## 0.5.3

### Изменено
- Из README и описания расширения убраны названия компании, репозиториев и маркетплейса плагинов.

## 0.5.2

### Исправлено
- «Плагин cex-sdd устарел» после обновления: из нескольких установок плагина бралась первая, а не та, что действует в проекте. Теперь выбор как в Claude Code: установка для этого проекта, иначе пользовательская, иначе самая свежая.
- Панель обновляется сразу после установки или обновления плагина (раньше — до 30 секунд).

## 0.5.1

### Добавлено
- **«Сейчас в этой ветке»**: шаг плана, который делается в текущей ветке — точно по PR или отметке в ветке, иначе предположительно по изменениям в ветке; раздел плана помечается «в работе».

### Изменено
- «Дальше» показывает шаг после текущего, а не текущий.

## 0.5.0

### Добавлено
- **id шагов плана и прогресс по PR**: `<!-- step: base -->` в `plan.md` и строка `Шаги plan.md: …` в описании PR; PR задачи читаются через `gh`. Без `gh` или id — прежний расчёт по галочкам.
- **Временные исключения**: метки `sdd-temp(<KEY>)` в коде и раздел «Временные исключения» в `design.md`; список с переходом к строке, ошибка перед шагом «Интеграция», предупреждение при расхождении таблицы и меток.

## 0.4.0

- Прогресс «сбрасывался» в новой ветке от `develop`; шаг, переформулированный в своей ветке, находится по разделу и номеру.
